## 4. A real diagnostic bug fixed (shipped)

`BbFreeCheck::Enabled()` is a Linux-only diagnostic and returns false on Apple. It gated
`Diagnostics::CheckSubmittedCopy` — the per-submission copy-vs-guest watchdog — so the one platform
that ever saw a torn submission could never run the check. Now gated on `BB_SUBMIT_CHECK=1`
instead, which works on macOS through the existing portable read path. Verified live: a 120 s hidden
run with `BB_SUBMIT_CHECK=1` logged `Submit check: 0 of 20000 …` / `0 of 40000 …` and exited 0.
Commits: native `dc2a2c8`, branch `fix/pm4-crash` `ee57500`.

## 5. Caveat that invalidates older measurements

`BB_COPY_GPU_BUFFERS` defaults to **false** and nothing in `tools/macOS` exports it (the comment in
`remote_front.cpp` calling it "run.sh's default" is stale; the repo-root Linux `run.sh` sets it, and
`tools/macos/run.sh` does not source that). With it off there is no copy to tear and
`BB_SUBMIT_ASYNC` is a no-op. Any pm4 measurement that did not export it measured nothing.
