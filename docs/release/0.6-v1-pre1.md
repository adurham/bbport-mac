A **test build** of bbport for Mac 0.6, for people willing to try it and report back.
**Experimental.** The latest regular release is still 0.4-v1. No game files are included: you
need your own decrypted copy of Bloodborne (CUSA03173) merged with the 1.09 update.

**Install:** download the zip below, open it and drag **bbport.app** into Applications (replace
an older one: your settings and saves are kept). You need an Apple Silicon Mac with macOS 26 or
later, Rosetta 2 and the Command Line Tools (for Python 3). The app isn't notarised: the first
time, allow it in **System Settings ▸ Privacy & Security ▸ Open Anyway**. The
**[user guide](https://github.com/bmy/bbport-mac/blob/macos-native-0.6/docs/USER_GUIDE.md)**
has the details.

## What's new

- **Based on bbport 0.6**, deadinside28's latest release.
- **The GPU work runs as native Apple Silicon code**, in a process of its own; only the game's
  own code still runs under Rosetta 2. Developer ▸ *In-process GPU (Rosetta)* switches back.
- **MetalFX**, Apple's upscaler, alongside FSR 3.1. If MetalFX ever fails, the game switches to
  FSR 3.1 by itself.
- **Every aspect ratio**, 4:3 to 32:9 ultrawide, with more of the game shown at the sides (or
  above and below) instead of a stretched picture. *Auto* follows your display (16:10 on a
  MacBook). New installs start at 16:9, 1920×1080, the PS4's own.
- **Less direct memory with an upscaler**: about 5 GB (instead of 9 GB above a 1080p output)
  while the game draws at 1080p or less before upscaling, more for larger scenes, up to 9 GB.
- **Fixed:** a crash with code 23 (an invalid vertex format the game sometimes writes).

## Known issues

- **Short pauses while shaders compile**, mostly when an area loads; the first launch shows a
  black window for a few minutes.
- **Geometry shaders are emulated** (Metal has none). If an effect looks wrong,
  `BB_GEOMETRY_SHADERS=0` in *Extra variables* skips those draws instead.
- **The in-game menu pointer** doesn't work with the native GPU process yet.
- **Online play** isn't available on the Mac.
- **Tested on one Mac** so far (M5 Max).

## Please report

On the [Issues page](https://github.com/bmy/bbport-mac/issues): your Mac (model, chip, memory),
macOS version, what you did and what happened, with the log attached (**Help ▸ Show the Last
Run's Log**, right after quitting the game).
